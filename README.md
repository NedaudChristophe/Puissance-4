# Puissance 4

Un jeu de Puissance 4 développé avec Symfony 6.4.

## Fonctionnalités

- Interface graphique moderne et responsive
- Animations fluides
- Détection automatique des victoires
- Alternance des tours entre les joueurs
- Possibilité de recommencer une partie

## Prérequis

- PHP 8.1 ou supérieur
- Composer
- Symfony CLI

## Installation

1. Cloner le dépôt :
```bash
git clone https://github.com/votre-username/puissance-4.git
cd puissance-4
```

2. Installer les dépendances :
```bash
composer install
```

3. Lancer le serveur de développement :
```bash
symfony server:start
```

4. Ouvrir votre navigateur à l'adresse : `http://localhost:8000`

## Comment jouer

1. Cliquez sur une colonne pour placer votre jeton
2. Le jeu alterne automatiquement entre les joueurs rouge et jaune
3. Le premier joueur à aligner 4 jetons gagne la partie
4. Utilisez le bouton "Nouvelle partie" pour recommencer

## Technologies utilisées

- Symfony 6.4
- PHP 8.1
- HTML5/CSS3
- JavaScript (ES6)
- Twig
